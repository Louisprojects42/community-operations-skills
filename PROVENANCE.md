# Provenance and scope

These are newly authored, general-purpose instructions synthesized from recurring patterns in local developer, community, and scientific-computing projects. The public pack does not copy application implementations, private records, operational IDs, proprietary datasets, or installed third-party skill files.

The worked examples are synthetic. Their names, prices, timelines, and datasets do not describe live services. Project-specific numerical thresholds, credentials, hosting endpoints, model claims, and role names have not been made universal requirements.

The collection uses the open Agent Skills layout. OpenAI-specific UI metadata is isolated in agents/openai.yaml; Claude packaging metadata is isolated in .claude-plugin/plugin.json. Both hosts use the same SKILL.md instructions.

External documentation is linked for version-specific details. Those sources and any future third-party data retain their own licenses; the MIT license applies to the original files in this pack.

Scientific workflows define checks and evidence requirements. They do not establish that any scientific model, original project, or release has passed those checks.
